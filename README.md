# Karnal Hometown Webpage

A beautifully styled personal landing page celebrating **Karnal, Haryana**, highlighting its historical significance, national institutions, and major tourist attractions.

## Features
- **Hero Section:** Full-screen hero background featuring Karnal with custom overlay styling.
- **National Pride Section:** Showcases key institutions and historical figures like Dr. Kalpana Chawla, NDRI, and CSSRI.
- **Top Spots:** Displays famous local landmarks such as Karnal Haveli, Karna Lake, and Cantonment Church Tower.
- **Custom Typography & Design:** Utilizes the Google Font 'Cinzel' with custom linear gradients and flexbox layouts.

## Built With
- **HTML5**
- **CSS3** (Flexbox, Gradients, Viewport Units)
- **Google Fonts**
